NLP & Machine Learning Pipeline

SmartCourse implements a dual-processing logic to handle both exact matches and conceptual queries.

1. TF-IDF Model

Classical content-based filtering. Uses N-Grams (Uni-grams & Bi-grams) and Cosine Similarity to find exact keyword overlaps in course descriptions.

2. Neural Model

Deep learning approach using all-MiniLM-L6-v2. Converts text into 384-dimensional dense vectors to find semantic relationships.
